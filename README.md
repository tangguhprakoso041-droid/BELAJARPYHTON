# OTOMASI INDUSTRI X CODING

Website pembelajaran statis untuk materi dasar Otomasi Industri dan Coding.

## File
- `index.html` — halaman utama
- `style.css` — tampilan/responsif
- `script.js` — simulator, modal materi, jam, dan kuis

## Cara menjalankan
Buka `index.html` di browser.

## Cara upload ke GitHub Pages
1. Buat repository GitHub, misalnya `website-otomasi`.
2. Upload ketiga file tersebut ke root repository.
3. Pastikan branch utama bernama `main`.
4. Buka Settings → Pages.
5. Pada Build and deployment pilih `Deploy from a branch`.
6. Branch: `main`, folder: `/ (root)`.
7. Save dan tunggu proses deployment selesai.

Website ini tidak memakai backend, database, CDN, atau library eksternal sehingga dapat berjalan offline setelah file disimpan.
